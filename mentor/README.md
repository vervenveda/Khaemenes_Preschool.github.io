# Khaemenes Preschool · Mentor Compatibility Doorway

Khaemenes Preschool no longer maintains a separate Mentor program.

The **single Khaemenes Academy Mentor is Archaemenes**, hosted with the Academy Family Registry at:

`https://vervenveda.com/Khaemenes_Academy.github.io/mentor/`

The legacy Preschool path:

`https://vervenveda.com/Khaemenes_Preschool.github.io/mentor/`

is retained only as a compatibility doorway and immediately redirects to the Academy Mentor.

## One-Mentor Contract

```text
Crechè Home
   ↓
Mentor button
   ↓
No active family session? → Academy Family Profile
   ↓
Active family session
   ↓
Selected learner in Academy Family Registry
   ↓
Archaemenes · Academy Mentor
```

A named child Mentor button first selects that learner in the shared Family Registry, then opens Archaemenes.

There is no independent Preschool Mentor identity, Guest Mentor, parent dashboard, learner-creation workflow, or separate Mentor progress authority in this directory.

## Family Registry Authority

Family and learner identity are owned by:

`https://vervenveda.com/Khaemenes_Academy.github.io/assets/khaemenes-family-registry.js`

Important shared keys include:

- `khaemenes_family_registry_v1`
- `khaemenes_active_family_v1`
- `khaemenes_active_adult_v1`
- `khaemenes_active_learner_v1`

Archaemenes is hosted under the same `vervenveda.com` origin as the Family Registry so the active learner can be read without placing family IDs or learner IDs in the URL.

## Early-Learner Boundary

Archaemenes remains one continuous Mentor identity but changes expression by learner stage.

For Preschool and Kindergarten learners, the Academy Mentor uses the **Wise Owl** expression and bounded prompt buttons rather than unrestricted private child text chat.

Older learners may use the normal Mentor conversation interface.

## Public Preschool Games

The Crechè games, stories, tools, favorites, rooms, and public activity catalog remain open without registration.

Only personalized Mentor continuity uses the Family Registry.
